## Ekstraksi ke project

Format runtime diambil dari tiap paket; FBX/OBJ duplikat, versi Unity, sampel, `.import`/`.uid` milik project asal, dan gambar promosi tidak disalin.

- **KayKit:** folder glTF + tekstur + `License.txt`. Medieval Hexagon hanya jembatan serta tile air/pantai/sungai; menara tidak diambil karena paket Free hanya punya varian berwarna tim (biru/hijau/merah/kuning), dan landmark memakai modul Dungeon.
- **Kenney:** UI Pack Grey + Extra (Default) dan font; Input Prompts keyboard/mouse + generic (Default); Rune Pack SVG vektor + PNG Grey/Tile; Particle Pack PNG transparan; Starter Kit Racing hanya `track-straight.glb`, `track-corner.glb`, dan `colormap.png`.
- **Tinysized SFX:** hanya kategori yang dipetakan (langkah, panah/quiver, botol/vial/cork, pedang, logam, whoosh, air, kunci, kayu/creak, kulit/kain). Bunyi rumah tangga yang tidak relevan dibuang, termasuk `chimes-wood-rattle.wav` 16,8 MB.
- **Musik eksplorasi:** WAV float 24 MB dikonversi ke **OGG Vorbis 1 MB** (durasi sama, 1:09), sesuai panduan Godot untuk musik panjang. WAV asli tetap di `downloads/`.
- **Shader:** hanya `.gdshader`, resource noise water, mesh/tekstur yang dirujuk, `LICENSE`, `README`. Scene dan material contoh tidak disalin karena memakai path `res://` project asal.
- **Rock Golem:** `.blend` sumber disimpan di `blendswap/rock_golem/source/` dengan `.gdignore`; `rock_golem.glb` sudah dikonversi lewat Blender 4.5.16 LTS dan berhasil dimuat Godot (satu mesh, 28 bone, tanpa animasi). Konversi mempertahankan basis low-poly dan tidak memerlukan tekstur gambar yang hilang dari sumber.

Import `.blend` di Godot dimatikan (`filesystem/import/blender/enabled=false`) supaya anggota tim tanpa Blender tidak gagal import. Folder kerja `tools/`, `downloads/`, dan `tmp/` diberi `.gdignore`.
