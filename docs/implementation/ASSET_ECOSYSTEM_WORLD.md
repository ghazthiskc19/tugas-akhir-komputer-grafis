# Audit Ekosistem World — KayKit

Tanggal observasi: **20 November 2026**. Scope: M10–M28, katalog/metadata dan preview resmi saja. Tidak mengunduh model/ZIP, membeli, mengimpor, membaca binary mesh, atau menguji Godot. Semua kandidat tetap **CANDIDATE**, bukan VERIFIED. Jumlah model pemasaran bukan persentase coverage game.

## Kesimpulan

**Forest Nature + Dungeon Pack (nama sekarang dari Dungeon Remastered) adalah pasangan utama yang lebih serasi untuk arah KayKit daripada mewajibkan Quaternius Nature/Ruins.** Forest menyediakan pohon/bush/grass/rocks; Dungeon menyediakan bangunan batu modular dan prop. Ini penilaian visual dari preview, bukan jaminan skala, collision, pivot, rig, atau performa. Quaternius tidak lagi diperlukan sebagai default nature/ruins; tetap alternatif bila bentuk reruntuhan/terrain KayKit tidak memenuhi layout. Tidak ada alasan mencampur publisher hanya untuk memenuhi pohon dan batu yang sudah ada dalam KayKit.

Namun **KayKit-only belum menutup game end-to-end**: empat glyph dan relief petunjuk, panel energi dengan connector lurus/siku, altar/seal, tiga artefak khas, tiga sockets gate, checkpoint state, terrain pulau 250×250 m, laut/sky/lighting dan feedback combat masih memerlukan pekerjaan atau pencarian model online lebih spesifik. Kitbash prop ≠ semua sistem tersebut siap. Untuk lore penjaga kuno, preview cemetery/skull bukan izin mengubah cerita menjadi undead.

**Cakupan scan: 15 produk individual berbeda**: 11 KayKit current yang relevan sebagai main kit/opsi bahan (sebagian sengaja tidak direkomendasikan sebagai final), 1 companion resmi Tiny Treats, 2 legacy untuk deduplikasi, 1 Furniture Bits yang relevansinya rendah. **3 bundle terpisah tidak dihitung sebagai pack baru.** Tidak menambah kitchen/sci-fi/holiday pack hanya untuk membesarkan angka.

## Cara membaca bukti, tier, lisensi dan risiko

- **CATALOG**: halaman pembuat dibaca; klaim isi/format belum diverifikasi dari arsip. **MANIFEST**: nama path pada tree GitHub resmi dibaca, bukan isi binary. **PREVIEW**: gambar resmi benar-benar dibuka. **INDEX_ONLY**: hanya hasil indeks resmi ketika halaman tidak dapat dibaca. **UNCONFIRMED**: detail yang sumber tidak menetapkan.
- Sejumlah `read` itch mengembalikan HTTP429. Browser normal milik agent berhasil membaca Resource, Hexagon, Board Game, Fantasy Weapons, Prototype, Legacy Dungeon, Pretty Park, Bits Bundle 1 dan Complete KayKit. Karena itu row tersebut **bukan INDEX_ONLY**. Website pembuat dan GitHub dipakai sebagai sumber pendamping, bukan mirror pihak ketiga. Gambar Dungeon Remastered lama MZkrCb memberi403; gambar katalog Dungeon current penggantinya berhasil dibuka.
- Angka harga di bawah adalah **minimum USD yang terlihat di halaman pada tanggal audit**, bukan perkiraan dari donation/sale/bundle. Free berarti tier Free, bukan EXTRA gratis. SOURCE menambahkan `.blend` dan mencakup EXTRA jika disebut; tidak berarti FBX/glTF/OBJ tidak bisa diedit tanpa SOURCE.
- **L1 = CC0 1.0 menurut halaman pembuat**: personal/komersial, tanpa atribusi wajib. [Deed resmi CC0](https://creativecommons.org/publicdomain/zero/1.0/) mengizinkan copy/modify/distribute; halaman KayKit juga meminta jangan menjual kembali salinan tanpa modifikasi atau mengaku membuatnya. Bedakan permintaan pembuat ini dari larangan redistribusi proprietary. Tetap simpan/periksa file lisensi tier yang kelak diperoleh sebelum file mentah masuk repo; preview dan logo tidak otomatis tercakup lisensi model.
- Risiko **LOW**: pemakaian prop statis/recolor/scale sederhana. **MEDIUM**: kitbash, pemisahan bagian, pivot/collision, penyesuaian proporsi/UV atau readability. **HIGH**: mengubah bentuk/semantik substansial, remodel, re-rig atau animasi custom. **UNKNOWN**: fakta model/tier tak tersedia. Risiko bukan estimasi jam atau janji pasti selesai.
- Semua format tabel adalah klaim katalog. Prop environment tidak memerlukan rig humanoid; tidak ada klaim skeletal rig/clip gameplay untuk prop kecuali dinyatakan. Animasi transform node dan logic interaksi tetap pekerjaan project.

## Deduplikasi dan bundle — bukan coverage baru

1. **Dungeon current naming trap:** `/kaykit-dungeon-pack` sekarang berisi versi1.1 dari **Remastered**, menurut changelog16July2026. `/kaykit-dungeon-remastered` masih dipakai website/GitHub lama. **Legacy sebenarnya `/kaykit-dungeon` (W13)**. Jangan menghitung current+remastered sebagai dua pack; jangan juga mencampur karakter legacy menjadi bukti rig current. Repo resmi1.0 adalah snapshot lama, bukan manifest versi1.1.
2. **Medieval:** W14 legacy memang produk lama berbeda, tetapi hex assets-nya sudah diremaster ke W03. Isi tidak identik, namun tidak boleh menjumlahkan seluruh hitungan marketing sebagai variasi unik game.
3. **[Bits Bundle 1](https://kaylousberg.itch.io/bits-bundle-1)** — CATALOG; **$19.95** menggabungkan Extra City Builder/Space Base/Furniture/Prototype/Restaurant/Halloween; **$29.95 Source** menambah `.blend`. CC0;OBJ/FBX/glTF. Tidak ada mesh eksklusif; mostly tidak relevan pada pulau ini. Jangan merekomendasikan kitchen/sci-fi karena ikut bundle.
4. **[Bits Bundle 2](https://kaylousberg.itch.io/bits-bundle-2)** — CATALOG; **$19.95** seluruh Extra Block/Resource/Holiday/RPG Tools/Fantasy Weapons/Board Game; **$29.95 Source**. CC0;OBJ/FBX/glTF. Metadata675+models bukan675kebutuhan tertutup. Jika kelak memilih beberapa Extra di sini, bandingkan biaya, bukan beli sekarang.
5. **[The Complete KayKit](https://kaylousberg.itch.io/kaykit-complete)** +[website pembuat](https://kaylousberg.com/game-assets/complete-kaykit-collection) — CATALOG; browser normal pada audit menunjukkan **$150.00**, includes SOURCE semua KayKit current+rilis itch masa depan. Indeks pernah menampilkan promo$99/harga potong, **bukan harga checkout saat audit**. Tidak ada konten pack eksklusif. **Tidak diasumsikan mencakup Tiny Treats**. Bukan solusi otomatis untuk glyph, energy network, golem boss atau animasi custom.

## Rekomendasi pengadaan berikutnya, bukan izin download

1. Tampilkan **WP01–WP03** dulu untuk menyetujui familyForest+Dungeon, lalu WP04/WP05 bila dock/crystal diperlukan. CoreFreeW01+W02 paling relevan; pilihExtraW01 hanya bila modularcliff/terrain atau varianwarnanya benar-benar dibutuhkan.
2. Remedy berbayar yang jelas: W04Extra untuk gems, W03Extra untuk dock/ship. SOURCE hanya opsi organized`.blend`, bukan syarat recolor/import/meshedit. Jangan membeli bundle untuk menutupi gap yang bundle tidak punya.
3. Belum ada paket yang membuktikan **M16,M17,M18seal,M24sockets,M26runtime,M28VFX** final. Pertahankan gap ini secara eksplisit; perlu pencarian online spesifik atau persetujuan bahwa mesh/materialmodification dari onlinebase mencakup bentuk baru tersebut. Tidak menjanjikan semuanya selesai dengan recolor/attachment.
4. Sampel nanti tetap harus melewati lisensi tier,materials/scale/pivot/collision,Compatibility rendering dan gameplayreadability. Audit ini tidak mengubah inventaris menjadi VERIFIED dan tidak mengubah lore/fitur.
