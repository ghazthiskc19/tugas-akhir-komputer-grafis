# Tugas Akhir Komputer Grafis

Project Unity 3D dengan Universal Render Pipeline (URP).

## Membuka project

1. Install **Unity 6.3 LTS (6000.3.9f1)** melalui Unity Hub.
2. Clone repository ini menggunakan Git.
3. Di Unity Hub, pilih **Add project from disk**, lalu pilih folder hasil clone yang berisi `Assets`, `Packages`, dan `ProjectSettings`.
4. Buka project dan tunggu proses import package selesai. Scene awal ada di `Assets/Scenes/SampleScene.unity`.

Folder `Library`, `Temp`, `Logs`, dan `UserSettings` dibuat ulang oleh Unity dan tidak disimpan di Git. File `.meta` harus ikut di-commit agar referensi asset tetap sesuai.

## Unity MCP

Project sudah menyertakan **MCP for Unity 10.3.0**. Bridge stdio otomatis aktif saat project dibuka. Untuk menggunakan tool MCP dari Codex atau client lain, konfigurasi server MCP di komputer masing-masing; konfigurasi akun dan server lokal tidak ikut disimpan di repository.
